# 事件与奇遇系统设计文档

## 一、系统概述

本游戏包含两种主要随机事件系统：
1. **好事/坏事事件**：普通随机事件，触发概率受气运影响
2. **奇遇事件**：多环选择型事件，需要玩家做出决策

---

## 二、事件系统

### 2.1 事件类型与权重

| 事件类型 | 权重 | 说明 |
|:---|:---:|:---|
| 修炼事件 | 40% | 基础修炼 |
| 财富事件 | 60% | 财富获取/消耗 |
| 好事事件 | 8% | 额外好事 |
| 坏事事件 | 8% | 额外坏事 |
| 奇遇事件 | 4% | 多环选择奇遇 |
| 突发事件 | 6% | 多结果突发事件 |

### 2.2 气运影响机制

| 气运范围 | 好事倍率 | 坏事倍率 |
|:---|:---:|:---:|
| > 130 | ×1.5 | ×0.5 |
| 100-130 | ×1.2 | ×0.7 |
| 70-100 | ×1.0 | ×1.0 |
| 40-70 | ×0.8 | ×1.3 |
| < 40 | ×0.6 | ×1.6 |

## 四、奇遇系统

### 4.1 奇遇概述

奇遇是一种**多环选择型事件**，玩家需要通过多个决策节点，最终获得奖励或物品。

**数据结构**：
```javascript
{
  title: '标题',
  desc: '描述',
  realmRange: [起始境界, 结束境界],
  type: 'technique' | 'treasure' | 'normal',
  rarity: 'common' | 'uncommon' | 'rare' | 'epic' | 'legendary',
  itemId: '物品ID',  // 仅功法/法宝奇遇
  rings: [
    {
      desc: '场景描述',
      choices: [
        {
          icon: '图标',
          text: '选项文字',
          hint: '风险提示',
          risk: 'high' | 'mid' | 'safe',
          requires: { power/talent/luck: 数值 },  // 可选
          nextRing: 下一环索引,
          reward: { 属性: 数值 }  // 中间退出奖励
        }
      ],
      finalReward: { giveItem: true } 或 { 属性: 数值 }  // 最终奖励
    }
  ]
}
```

### 4.2 奇遇类型

| 类型 | 说明 | 最终奖励 |
|:---|:---|:---|
| technique | 功法奇遇 | 获得功法 |
| treasure | 法宝奇遇 | 获得法宝 |
| normal | 普通奇遇 | 属性提升/财富 |

## 五、化神期

游戏在突破化神时结束，因此：
- 无化神期好事/坏事事件
- 无化神期奇遇
- 突破化神成功后跳转到结局页面

## 六、设计原则

### 6.1 数值平衡原则

1. **好事/坏事对称**：坏事数值约为好事的50%-100%
2. **境界递进**：每个境界的奖励/惩罚数值约为前一境界的10倍
3. **气运影响**：气运越高，遇到好事概率越高，坏事概率越低

### 6.2 叙事设计原则

1. **符合境界**：事件描述应与当前境界相匹配
   - 炼气期：凡人、山洞、散修、灵草
   - 筑基期：宗门、秘境、前辈洞府
   - 金丹期：上古遗迹、大宗门、元婴长老
   - 元婴期：仙道大会、远古大能、仙门大战

2. **风险与收益对等**：高风险选项需要满足更高的属性要求，但奖励更丰厚

3. **奇遇多样性**：
   - 功法/法宝奇遇：提供强力装备
   - 普通奇遇：提供属性提升和财富
