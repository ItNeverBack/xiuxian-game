# 成就系统设计文档

> 本文档为游戏成就系统的设计参考，包含成就分类与触发条件。

---

## 一、系统概述

成就系统用于记录玩家在游戏过程中的里程碑和特殊成就，激励玩家探索游戏内容，丰富游戏体验。

### 1.1 设计原则

1. **渐进性**：成就按难度分为多个等级，引导玩家逐步深入
2. **多样性**：覆盖游戏的各个系统和玩法
3. **可见性**：玩家可随时查看已获得/未获得的成就

### 1.2 成就分类

成就分为两大类：

| 类型 | 说明 | 数量 |
|:---|:---|:---:|
| 单局成就 | 必须在一局游戏内完成，新游戏重置进度 | 约 15 个 |
| 累积成就 | 可通过多局游戏累积进度，最终获得 | 约 30 个 |

### 5.2 界面元素

- **成就卡片**：显示成就图标、名称、类型标签、稀有度、进度
- **视觉状态**：
  - **已解锁**：闪闪发亮（发光动画效果），文字/边框显示对应稀有度颜色
  - **未解锁**：灰色显示（opacity: 0.5），显示当前进度
  - **隐藏成就**：达成前显示为问号，达成后解锁名称和条件
- **稀有度颜色**：普通(白)、精良(蓝)、稀有(紫)、史诗(橙)、传说(金)
- **解锁动画**：获得成就时的弹窗通知 + 卡片发光效果

## 六、数据结构

### 6.1 成就对象

```javascript
const achievement = {
  id: 'A-01',           // 成就ID
  name: '初遇仙缘',       // 成就名称
  desc: '完成第一个奇遇',  // 成就描述
  category: 'adventure', // 分类
  rarity: 'common',      // 稀有度
  type: 'cumulative',    // 类型：single (单局) / cumulative (累积)
  condition: {
    type: 'adventureComplete',
    count: 1
  },
  hidden: false,         // 是否隐藏
  unlocked: false        // 是否已解锁
};
```

## 七、实现要点

### 7.1 触发检测

在以下时机检测成就触发：
- 属性变化时（修为、财富、寿元等）
- 事件触发时（好事、坏事、奇遇）
- 境界突破时
- 游戏存档/加载时
- 新游戏开始时（重置单局数据）

### 7.2 单局/累积区分

| 操作 | 单局成就 | 累积成就 |
|:---|:---:|:---:|
| 游戏存档时 | 保存进度 | 保存进度 |
| 加载存档时 | 恢复进度 | 恢复进度 |
| 新游戏开始 | **重置进度** | 保留进度 |
| 获得成就 | 标记解锁 | 标记解锁 |

### 7.3 通知机制

获得成就时：
1. 弹出成就通知（右下角），显示成就类型标签
2. 播放音效（可选）
3. 添加到成就面板

### 7.4 存档同步

成就数据需要：
- 单局数据：与游戏存档绑定，新游戏时重置
- 累积数据：独立存储，跨存档保留
- 自动保存到 localStorage
